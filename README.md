# RAO

Registro de ganado de los ranchos. App web instalable (celular y computadora) que guarda los datos en Firebase.

- La app publicada es `index.html` con sus archivos (GitHub Pages).
- `herramientas/build.py` genera `index.html` a partir del archivo de la app RAO.
- `herramientas/firestore.rules` son las reglas de acceso de Firestore (se pegan en la consola de Firebase).
